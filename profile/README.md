Tables should open on an MSI you build, not as a locked binary. Extra files wait for their own title.

## How Master Packager Pro Sits

Master Packager Pro does not replace the MSI files you already keep. It sits beside them as a named MSI editor for Master Packager Pro MSI you build.

## Traffic Light

| Signal | On the Master Packager Pro shop package | What you do |
|--------|-----------------------------------------|-------------|
| Green | Named MSI, tables on a file you own | Continue the same package table |
| Amber | Tables from two MSI files mixed | Split the set before a large change |

## After a Week

A week in Master Packager Pro is not more open tables. It is the same MSI editor, a shorter table list, and a note that still makes sense on Monday. Leave the shop package quieter than the session you opened.
